# AI Productivity Hub

Build a modern, responsive frontend-only SaaS web application called AI Workplace Productivity Assistant.

The app helps professionals complete common workplace tasks using AI. Keep the project lightweight and suitable for a free Lovable account.

Main Requirements

Create a clean dashboard with:

A left sidebar navigation.

Dashboard/home screen.

Smart Email Generator.

AI Research Assistant.

AI Workplace Chatbot.

Responsive mobile layout.

Grey, black, and white professional color palette.

Modern typography, cards, buttons, icons, subtle borders, and smooth hover states.

No login, registration, authentication, payments, or user accounts.

1. Smart Email Generator

Create a simple interface where the user can enter:

Email purpose

Recipient/context

Key points

Optional additional instructions

Provide tone selection:

Formal

Friendly

Persuasive

Include a Generate Email button.

Display the AI-generated email in an editable text area/card with:

Edit functionality

Copy button

Regenerate button

Clear/reset button

Use structured prompts so the generated emails are professional, concise, and appropriate for workplace communication.

2. AI Research Assistant

Create an interface where users can enter:

Research topic or question

Optional article/text

Include a Research & Summarize button.

Display results in organized sections:

Summary

Key Insights

Important Points

Recommendations

Make all generated content editable and easy to copy.

3. AI Workplace Chatbot

Create a modern chat interface similar to a professional AI assistant.

Include:

Message history during the current session

User and AI message bubbles

Text input

Send button

Suggested workplace prompts

Clear chat button

The assistant should be designed for workplace productivity, brainstorming, writing assistance, research, planning, and general professional questions.

Dashboard

Create a simple homepage showing:

Welcome message

Short description of the assistant

Three feature cards:

Smart Email Generator

AI Research Assistant

AI Workplace Chatbot

Quick-action buttons to open each feature.

Keep the dashboard visually clean rather than adding unnecessary statistics or complex analytics.

AI Prompt Structure

Design each AI feature around structured prompts that clearly define:

The user's task

Relevant context

Desired tone

Expected output format

Professional workplace guidelines

Make the prompts easy to maintain and modify later.

Responsible AI

Add a small but visible Responsible AI disclaimer in the application.

Example concept:

“AI-generated content may contain errors or omissions. Review outputs for accuracy, context, privacy, and appropriateness before using them in professional settings. Do not enter confidential or sensitive information.”

Technical Constraints

Frontend only.

No backend.

No database.

No authentication or user accounts.

Do not create login or registration pages.

Avoid unnecessary external services or complex infrastructure.

Keep the application lightweight and easy to run.

Use mock/demo AI responses if a real AI API is not configured.

Structure the application so an AI API can be connected later without redesigning the UI.

Overall Design Direction

The final application should look like a polished, modern productivity SaaS product: minimal, professional, spacious, and easy to use.

Use primarily black, charcoal, dark grey, light grey, and white. Avoid bright colors and excessive gradients.

Prioritize excellent responsive design, intuitive navigation, clear hierarchy, editable AI outputs, and a professional workplace aesthetic.
